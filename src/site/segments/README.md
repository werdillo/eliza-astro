# segments

The three HoReCa segments (hotels, restaurants, cafes): the grid on the HoReCa page, and the list of
segments with their photographs and their project links. The segments are in `data.ts`.

Door (`index.ts`): `SegmentsGrid`, `horecaItems`, `horecaPage`, `hotelsPage`, `cafePage`, `projectsPage`,
`secondaryLinks` (the box's menu entry).

# components

The UI kit: presentational parts that know no business subject. They import only `core/` and each
other, through their doors.

Boxes:
- `typography/` — the nine text styles (H1–H6, P1–P3): the only place a size, weight or line height is set.
- `slider/` — generic Swiper container.
- `burger-menu/` — mobile menu button and panel.
- `image-tile/` — a photograph with a label, linking somewhere.
- `landing-tile/` — a picture on a light card with a caption below.
- `grid-toggle/` — chooses 3 or 4 product cards in a row (1 or 2 on a phone), remembered in the visitor's browser.

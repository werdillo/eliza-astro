# grid-toggle

A control that chooses how many product cards stand in a row: 3 or 4 above 768px, 1 or 2 on a phone. Each
choice stays in the visitor's browser and is set on `<html>` as `data-grid-cols` / `data-grid-cols-mobile`;
`app/styles/base.css` applies them to `.product-list`.

Door: `GridToggle`.

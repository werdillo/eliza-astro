# catalogs

The printed catalogues page: a cover for each catalogue, linking to its PDF. With scripts on, the link opens
the PDF in a reader on the page (`PdfViewer` from `features/pdf-viewer`, in its book mode).
The address keeps the place, for example `#catalog-2019-12`. The catalogues and their labels are in `data.ts`.

Door (`index.ts`): `CatalogsList`, `catalogsPage`, `catalogsNav`.
